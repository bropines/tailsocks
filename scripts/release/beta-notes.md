> **This is a beta**: a build of the next version, published before it is finished so that it can be tested. It may break. It is the same app, signed with the same key — it installs over the stable release and keeps your data — and the app offers it only with *Receive beta versions* switched on (Settings → Appearance & language).
>
> To go back to the stable channel, install the next stable APK over it when that is released: same signature, nothing is lost. Until a stable release newer than this beta exists the beta stays — Android does not install an older version over a newer one.

# Архитектура TailSocks

TailSocks — это гибридная многослойная система, объединяющая Go-демон Tailscale, C-туннель `hev-socks5-tunnel`, JNI-мост ByeDPI и нативный интерфейс Jetpack Compose Material 3.

---

## 🏗️ Слои Архитектуры

```
┌─────────────────────────────────────────────────────────────┐
│                    Jetpack Compose UI                       │
│           (MainActivity, Settings, Serve, Logs)             │
└──────────────────────────────┬──────────────────────────────┘
                               │ JNI (Gomobile / LocalSocket)
┌──────────────────────────────▼──────────────────────────────┐
│                    Go Core (appctr.so)                      │
│     - Patched tailscaled v1.98.3                            │
│     - LocalAPI v0 Client (Unix Socket)                      │
│     - Custom SOCKS5 & MagicDNS Proxy (1053)                 │
│     - Embedded ByeDPI JNI Proxy                             │
└──────────────────────────────┬──────────────────────────────┘
                               │ SOCKS5 Local Loopback
┌──────────────────────────────▼──────────────────────────────┐
│                Native TUN Engine (C Library)                │
│                 hev-socks5-tunnel (libhev.so)               │
└─────────────────────────────────────────────────────────────┘
```

---

## 🛠️ Основные Модули

1. **Go Core (`appctr`)**:
   - Работает на базе пропатченного демона Tailscale (`v1.98.3`).
   - Управляется **на 100% без CLI** через Unix сокет `tailscaled.sock` по протоколу LocalAPI v0.
   - Изолирует данные каждого профиля в `/files/states/{id}/`.

2. **DNS & MagicDNS**:
   - Использует кастомный DNS-сервер на Go (порт 1053), оборачивающий UDP DNS-запросы в TCP-фреймы через SOCKS5 для обхода ограничений Android.

3. **Обход DPI (ByeDPI)**:
   - Встроенная нативная C-библиотека ByeDPI с привязкой к случайному IP из диапазона `127.2.2.2/8` и случайному порту при каждом старте.

4. **Прозрачный TUN (hev-socks5-tunnel)**:
   - Перехватывает системный трафик Android и оборачивает его в SOCKS5 туннель без модификации сетевого стека Go ядра.

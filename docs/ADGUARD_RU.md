# 🛡️ Использование TailSocks DNS совместно с AdGuard

Чтобы использовать внутренний DNS TailSocks (для разрешения узлов `*.ts.net` и Split-DNS) параллельно с AdGuard, выполните следующие шаги для предотвращения зацикливания маршрутизации.

---

### 1. Настройка DNS в TailSocks
* Откройте **Настройки TailSocks**.
* В разделе **Настройки DNS** укажите адрес прослушивания (например, `127.0.0.1:1053`).
* Убедитесь, что служба **Активна**.

---

### 2. Отключение фильтрации AdGuard для TailSocks (Обязательно!)
Чтобы предотвратить рекурсивное зацикливание (AdGuard -> TailSocks -> AdGuard):
* Перейдите в AdGuard -> **Управление приложениями**.
* Найдите **TailSocks**.
* **Отключите** пункт "Направлять трафик через AdGuard" (или "Защита AdGuard").

---

### 3. Низкоуровневые настройки AdGuard
* Откройте **Настройки AdGuard**.
* Перейдите в **Настройки** -> **Расширенные** -> **Низкоуровневые настройки**.
* Найдите **Резервные upstream-серверы** (`dns.fallback_upstream`).
* Добавьте адрес DNS TailSocks с новой строки:
    ```text
    127.0.0.1:1053
    ```
* Найдите **Резервные домены** (`dns.fallback_domains`).
* Добавьте маски для адресов вашей сети Tailnet:
    ```text
    *.ts.net
    *.YOUR_SPLIT_DOMAIN.site
    ```
    *(Замените `YOUR_SPLIT_DOMAIN.site` на ваш корпоративный или приватный домен, настроенный в Tailscale).*

---

### 4. Подключение AdGuard к SOCKS5 прокси TailSocks
Так как TailSocks работает в пользовательском пространстве, одного получения IP недостаточно — AdGuard должен знать, как доставить пакеты на этот IP.

#### Вариант A: Прямой прокси (Просто)
* В AdGuard перейдите в **Настройки** -> **Прокси**.
* Добавьте **SOCKS5 Прокси**: `127.0.0.1:1055` (или ваш порт).
* Включите его для всего трафика или через правила "Проксируемые приложения".

---

### 5. Частые вопросы: Маршрутизация без Exit Node
**Вопрос:** Если я не выбрал **Exit Node**, куда уходит мой интернет-трафик?

**Ответ:**
* **Трафик Tailnet (Внутренний):** Запросы к `100.x.y.z` или `*.ts.net` всегда туннелируются в зашифрованный канал Tailscale к вашим узлам.
* **Интернет-трафик (Публичный):** Если Exit Node не выбран, Tailscale передаёт обычные интернет-запросы напрямую в **родную сеть телефона** (Wi-Fi или 4G/5G).
* **С выбранным Exit Node:** Весь трафик шифруется и уходит на Exit Node.

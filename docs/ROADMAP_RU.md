# План развития проекта (Roadmap)

Этот документ описывает планируемые функции, архитектурные улучшения и цели рефакторинга проекта TailSocks.

---

## ✅ Завершённые этапы
- [x] **Стабильность ядра:** Пассивное управление демоном и декларативная конфигурация.
- [x] **Передача файлов:** Реализация Taildrop с интеграцией в Storage Access Framework.
- [x] **Изоляция профилей:** Мультиаккаунтная система с независимыми каталогами состояния.
- [x] **Сетевые возможности:** Кастомное DNS-обертывание и поддержка Exit Nodes.
- [x] **Tailscale Serve/Funnel:** Нативный UI для хостинга сервисов и публичного доступа.
- [x] **Local API v0:** Управление 100% без CLI через Go-HTTP мост.
- [x] **Интеграция с системой:** Плитка Быстрых настроек (Quick Settings Tile).
- [x] **Поиск и фильтрация:** Функция поиска в списке узлов (Peers) и логах.
- [x] **Защита от энергосбережения:** Диалог помощи пользователю по выходу из оптимизации батареи.
- [x] **Прокси панели управления:** Поддержка SOCKS5/HTTP прокси для трафика управления с фиксом обхода netns.
- [x] **Зашифрованные бэкапы:** Зашифрованный бэкап состояния приложения (AES-GCM) для защиты ключей.

---

## 🔮 Будущие планы
- [ ] **AI Model Context Protocol (MCP) Сервер:** Встроенный MCP-сервер (JSON-RPC поверх SSE / LocalSocket) поверх `appctr/api.go` LocalAPI, позволяющий ИИ-ассистентам (Claude, Cursor, локальные LLM) опрашивать статус, менять Exit Nodes и управлять профилями.
- [ ] **Нативный Kotlin LocalAPI Мост:** Перевод вызовов LocalAPI с Go (`appctr`) на прямые OkHttp/UnixDomainSocket вызовы в Kotlin.
- [ ] **Анализатор трафика:** Реализация инспектирования активных соединений и запросов MagicDNS прямо в приложении.
- [ ] **Расширенные сетевые функции:** Поддержка пользовательских карт DERP и переопределение региональной маршрутизации.

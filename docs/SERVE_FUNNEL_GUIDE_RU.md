# Руководство по Tailscale Serve & Funnel

Tailscale Serve и Funnel позволяют локально пробрасывать порты с устройства Android в сеть Tailnet или напрямую в публичный интернет с автоматическим выпуском TLS-сертификатов Let's Encrypt.

---

## 🌐 Разница между Serve и Funnel

- **Tailscale Serve**: Пробрасывает локальный порт только **внутри закрытой сети Tailnet** (доступно только вашим авторизованным устройствам).
- **Tailscale Funnel**: Пробрасывает локальный порт **в публичный интернет** через шлюзы Tailscale с валидным HTTPS-сертификатом.

---

## 🛠️ Паттерн "Reset-then-Apply"

В соответствии с архитектурным стандартом проекта TailSocks:
При каждом обновлении конфигурации Serve/Funnel сначала отправляется пустой JSON-объект `{}` на эндпоинт LocalAPI `/localapi/v0/serve/config` для сброса зависшего состояния демона, а затем применяется новая конфигурация.

---

## 🔒 Использование виртуальных сервисов (`svc:`)

Для создания именованного сервиса в сети Tailnet используйте виртуальные сервисы `svc:`. 
*Обратите внимание: созданные сервисы требуют однократного ручного подтверждения в Tailscale Admin Console.*

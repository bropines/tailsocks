The source is at [github.com/bropines/tailsocks](https://github.com/bropines/tailsocks), under the BSD-3-Clause license.

- [Building](/tailsocks/developers/building/) — the Android SDK and NDK, Go and `gomobile`. `appctr/build.sh` makes the core, Gradle makes the APK.
- [Architecture](/tailsocks/developers/architecture/) — a patched `tailscaled`, a Go bridge and a Compose app. One state directory and one set of preferences per account.
- [Contributing](/tailsocks/developers/contributing/) — rules for a first pull request: patches, the three tunnel modes, commits, the changelog, testing.
- [Translating](/tailsocks/developers/translating/) — on Hosted Weblate, in the browser. English is the source, Russian is kept alongside it.
- [Releasing](/tailsocks/developers/releasing/) — a release is a tag. Two channels, version codes, what F-Droid depends on.

Also on GitHub: the [Root Mode guide](https://github.com/bropines/tailsocks/blob/main/docs/ROOT.md) and the [changelog](https://github.com/bropines/tailsocks/blob/main/CHANGELOG.md).

Questions the pages do not answer: open an issue on [GitHub](https://github.com/bropines/tailsocks/issues).

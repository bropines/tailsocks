---
title: Обход блокировок
description: Как достучаться до сервера координации, если Tailscale блокируют или ломают.
---

Чтобы войти и узнать о ваших устройствах, узел говорит с сервером координации — Tailscale или вашим Headscale. Если эту связь режут, в разделе Настройки → **Обход блокировок** есть четыре средства. Когда сервер недоступен, на баннере главного экрана появляется кнопка **Обход**, которая ведёт сюда же.

Через них идёт только канал управления. Трафик между вашими устройствами — нет.

## Только порт 443

Карточка **Канал управления**, включено по умолчанию с 4.10.1.

Tailscale открывает канал управления на обычном порту 80. В некоторых сетях рукопожатие проходит, а дальше поток молча обрывается: устройство входит, но карту сети не получает и висит на *Подключении*. Через 443 весь обмен идёт внутри TLS.

Выключайте, только если порт 443 до сервера в вашей сети не работает.

## Обход DPI

**Включить обход ByeByeDPI** запускает [ByeDPI](https://github.com/hufrea/byedpi) прямо в приложении и пускает через него канал управления. Он слушает случайный loopback-адрес и порт, новые при каждом запуске.

- **Флаги ByeByeDPI** — параметры десинхронизации. По умолчанию `-o1 -a1 -r-5+se`. Флаги, которые он не принял, заменяются встроенными, и карточка показывает, что работает на самом деле.
- **Принудительный IPv4 (Отключить IPv6)** — если рукопожатия по IPv6 не проходят.

Пока обход включён, он заменяет прокси для Control Plane.

## Прокси для Control Plane

**Прокси Control Plane** пускает канал управления через ваш собственный прокси: SOCKS5, HTTP или HTTPS, с логином и паролем, если нужно.

## Запуск без сервера

**Запускаться по сохранённой карте сети**: демон хранит последнюю карту сети и при запуске сразу соединяется по ней с вашими устройствами, не дожидаясь сервера. Сеть поднимается, даже если сервер медленный или заблокирован; новые устройства и изменённые правила приедут, когда он ответит.

Разрешает это сервер, для каждого устройства отдельно, — карточка скажет, разрешил ли. **Очистить кэш карты сети** удаляет сохранённые карты.

## Резервный DNS

Если DNS тейлнета не отвечает, спрашиваются Настройки → DNS → **Резервные DNS-серверы**:

- **Резервные DNS** — обычный DNS, например `8.8.8.8:53,1.1.1.1:53`.
- **DoH URL резервного DNS** — DNS через HTTPS, последняя попытка, например `https://1.1.1.1/dns-query`.

Главный экран тогда пишет *DNS Tailscale не отвечает* и отвечают ли пока резервные.

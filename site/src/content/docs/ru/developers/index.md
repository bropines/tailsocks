Исходники — на [github.com/bropines/tailsocks](https://github.com/bropines/tailsocks), под лицензией BSD-3-Clause.

- [Сборка](/tailsocks/ru/developers/building/) — Android SDK и NDK, Go и `gomobile`. `appctr/build.sh` собирает ядро, Gradle — APK.
- [Архитектура](/tailsocks/ru/developers/architecture/) — `tailscaled` с патчами, мост на Go и приложение на Compose. У каждого аккаунта свой каталог состояния и свои настройки.
- [Участие в разработке](/tailsocks/ru/developers/contributing/) — правила для первого pull request: патчи, три режима туннеля, коммиты, список изменений, тесты.
- [Перевод](/tailsocks/ru/developers/translating/) — на Hosted Weblate, прямо в браузере. Исходный язык — английский, русский ведётся вместе с ним.
- [Выпуск релизов](/tailsocks/ru/developers/releasing/) — релиз — это тег. Два канала, коды версий, на чём держится F-Droid.

Ещё здесь: [Root-режим изнутри](/tailsocks/ru/root-mode-internals/) и [список изменений](/tailsocks/ru/changelog/).

Если ответа на страницах нет — откройте issue на [GitHub](https://github.com/bropines/tailsocks/issues).
